# 开发计划与当前状态

0.7.0 为首个公开版本；0.8.0-rc.2 实现本轮开发者能力补充。对应关系见 [覆盖表](development-matrix.md)，使用见 [开发者编辑能力](developer-workflows.md)，证据见 [验证记录](validation.md)。

| 范围 | 本轮交付 |
| --- | --- |
| Core | 文件/目录覆盖、目标配置、include 搜索路径、扩展验证接口与独立示例 |
| RISC-V | 补全、参数、include/宏、ISA 作用域、基础诊断与修复、引用/重命名、结构/折叠/格式化 |
| GNU ld | 补全、定义与引用、INCLUDE、常量/布局诊断、结构/折叠/格式化 |
| 跨语言 | 源码别名、后台反解、实际二进制符号和调试位置映射 |
| 验证 | 平台编辑器集成、二产品二进制检查、真实工具链、独立扩展示例构建 |

继续迭代的深度包括更多 ISA/方言、完整预处理与宏实例化、复杂 ABI/优化后调试映射、链接期输入节布局及更多产品/OS 验证。这些不等同于本轮已实现的基础编辑能力，也不通过运行不明项目构建来猜测结果。

版本遵循 SemVer 2.0.0，官方模块同版本交付。未发布的开发包和已审核的商店版本明确区分；已发布版本内容不覆盖修改。
