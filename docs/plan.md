# 开发计划

当前发布候选为 0.7.0：文件图标、汇编标签及宿主源码符号导航已完成，并新增同文件宏定义跳转。79 项测试与 RustRover/CLion 六组二进制兼容性检查通过。用户确认 0.6 真实 IDE 功能与安装、升级、模块组合验收完成；新宏导航单独由自动化覆盖。

| 阶段 | 工作 | 完成标准 |
| --- | --- | --- |
| 0/1 | RustRover 构建基线、两个独立插件、扩展发现、项目设置、语言分发 | 编译打包成功；核心单独运行；RISC-V 可注册；缺少扩展时回退；切换后文件重新解析 |
| 2 | GNU 风格 RISC-V Lexer、容错 Parser、PSI、颜色设置 | 指令/寄存器/标签上下文分类正确；编辑不完整代码可恢复；覆盖 `.s/.S/.asm` 与注释/字符串边界 |
| 3 | RV32I/RV64I 资料、整数寄存器与 ABI 别名、常用伪指令和指示符、Hover | 离线文档；Hover 与 Quick Documentation 一致；明确指令与伪指令区别；来源和许可可追踪 |
| 4 | 独立 GNU ld 插件 | MEMORY、SECTIONS、表达式和内建函数的基础高亮与说明；不依赖架构插件 |
| 5 | 扩展契约验证、插件组合与发布检查 | 增加架构无需修改核心分发；RustRover 验收通过；再扩展 CLion、IDEA 验证矩阵 |

首个可用版本先交付 RV32I/RV64I；M/A/F/D/C 等扩展逐批加入。当前不包含汇编执行、调试、完整宏展开或完整指令合法性诊断。

文件/目录覆盖设计、GNU 风格方言范围与 `.S` 策略已记录在 `riscv-syntax.md`；本阶段设置 UI 仍仅提供项目级架构选择。
