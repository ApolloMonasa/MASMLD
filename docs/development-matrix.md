# 0.8 开发者能力覆盖表

本轮对应此前提出的各类缺口，实际入口、支持范围与边界如下。版本为 0.8.0-dev，未覆盖发布的 0.7.0 二进制。

| 原缺口 | 本轮实现 | 边界 |
| --- | --- | --- |
| Core 文件/目录架构与方言设置 | 目录、文件和 glob 覆盖；profile、目标和 GNU 方言验证 | 目前仅 GNU；未安装架构回退 Generic |
| 扩展 API 与示例 | 可选目标验证接口、契约说明、独立 arch-example 构建 | 示例只验证扩展接入，不是 ARM/x86 实现 |
| RISC-V 补全及参数提示 | 465 项目录、寄存器、符号、有效宏、参数、项目导出索引 | 未囊括 ISA 所有扩展和伪指令 |
| include 与跨文件宏 | 搜索路径、文件跳转、静态包含顺序、循环与资源限制、purgem | 不执行宏实例化、条件或预处理 |
| RV32/RV64 与 ISA 选择 | I/M/A/F/D/C、Zicsr/Zifencei；按位置解析 option push/pop/arch；补全/文档过滤 | 私有及其他扩展未作合法性保证 |
| 错误提示及修复 | XLEN/扩展、已知操作数形状、寄存器、部分立即数、舍入模式；ISA 快速修复；不可导航符号弱提示 | 不将外部符号缺少源码定义判为链接错误 |
| 引用及安全重命名 | 标准引用搜索、数字局部标签的本文件引用、命名符号重命名、重复赋值组、冲突提示与预览 | 数字标签拒绝重命名；纯文本和外部合成导航目标只读 |
| RISC-V 结构/折叠/格式化 | 标签/常量/宏结构、块折叠、标准 Reformat Code | 保守修改 token 间距；不重排指令或展开宏 |
| GNU ld 补全与导航 | 符号、MEMORY、输出节、REGION_ALIAS、命令和函数 | 不把输入节通配符当输出节引用 |
| GNU ld INCLUDE | 相对目录和搜索路径解析、包含图内引用 | 非 .ld 包含文件可位置导航；完整编辑需正确文件关联 |
| GNU ld 表达式与诊断 | 常量运算和常用函数、区域范围/重叠、固定输出地址和显式对齐提示 | 输入节大小、单参数 ALIGN、最终位置计数器、溢出和循环保持未知；普通符号允许合法重赋值 |
| GNU ld 结构/折叠/格式化 | 类型化定义、Structure、括号与注释折叠、Reformat | 不执行模板或预处理 |
| Rust/C/C++ 链接符号映射 | 宿主索引、常见源码导出名/别名、基本名字解码、后台 demangler、实际目标文件符号与调试行导航 | 完整修饰名和源码行依赖配置工具与调试信息；未提供构建器或调试器 |

验证包含模型测试、真实平台编辑器集成、两个 IDE 的二进制验证，以及实际 C/C++/Rust 与 LLVM 工具链检查。精确结果见 validation.md 与交付包 manifest.json。新版本未冒用用户对旧版的图形 IDE 验收结论。
